# Migrating from 0.6.x to 0.7.0

This guide covers every breaking or action-required change between the 0.6.x
series and 0.7.0. 0.7.0 finalizes the breaking boundary promised in 0.6:
the minimum toolchain moves to Rust 1.98, and every 0.6 compatibility alias
is removed. The JSONL contract, CLI surface, exit-code mapping, and report
formats are unchanged.

Related references:

- [CHANGELOG](../../CHANGELOG.md) (Unreleased section — full entry list)
- [Library API](../reference/LIBRARY_API.md)
- [0.6 migration](./0.6.md) (the window these removals close)

## 1. MSRV 1.95 → 1.98

Set your toolchain to Rust 1.98 or later:

```toml
[package]
rust-version = "1.98"
```

```console
$ rustup update stable
$ rustc --version
rustc 1.98.0 (or later)
```

No language or dependency changes are required beyond the toolchain itself;
the workspace was verified clean under exactly 1.98 (check plus both
clippy gate legs, zero new findings).

## 2. Removed facade aliases (`copybook` crate)

Each alias maps to one canonical path. Replace the import, nothing else
changes: the underlying items are untouched re-exports of the same owners.

| 0.6 alias | 0.7 replacement |
| --- | --- |
| `copybook::codepage::Codepage` (and errors, `space_byte`, `get_zoned_sign_table`) | `copybook::charset::…` |
| `copybook::contracts::{FeatureFlags, …}` | `copybook::core::feature_flags::…` |
| `copybook::determinism::…` | `copybook::codec::determinism::…` |
| `copybook::fixed::…` | `copybook::framing::fixed::…` |
| `copybook::options::…` | `copybook::codec::options::…` |
| `copybook::overpunch::…` | `copybook::codec::numeric::overpunch::…` |
| `copybook::rdw::…` | `copybook::framing::rdw::…` |
| `copybook::record_io::…` | `copybook::codec::record::…` (or `copybook::codec::file::dispatch`) |

0.6 example:

```rust
use copybook::codepage::Codepage;
use copybook::rdw::RdwHeader;
```

0.7 example:

```rust
use copybook::charset::Codepage;
use copybook::framing::rdw::RdwHeader;
```

## 3. Removed crate-level shims

The 0.6 compatibility items in the `copybook-codepage`, `copybook-lexer`,
and `copybook-dialect` crates are removed. The crates remain published
under their names as empty shells; depend on the owners instead.

| 0.6 shim | 0.7 replacement |
| --- | --- |
| `copybook_codepage::{Codepage, ParseCodepageError, ParseUnmappablePolicyError, UnmappablePolicy, space_byte, get_zoned_sign_table}` | `copybook_charset::…` |
| `copybook_lexer::{CobolFormat, Lexer, LexerOptions, Token, TokenPos}` | `copybook_core::lexer::…` |
| `copybook_dialect::{Dialect, effective_min_count}` | `copybook_core::dialect::…` |

## 4. Removed panicking RDW constructors

`RdwRecord::new`, `RdwRecord::with_reserved`, and
`RdwRecord::recompute_length` (deprecated since 0.4.3) are removed. They
panicked on oversize payloads; the fallible replacements have identical
behavior on success and return `CBKF102_RECORD_LENGTH_INVALID` instead of
panicking:

```rust
let record = RdwRecord::try_new(payload)?; // was RdwRecord::new(payload)
record.try_recompute_length()?;            // was record.recompute_length()
```

## 5. Retained deprecations

The 0.5.0 Arrow legacy surface (`copybook-arrow::legacy`) is unchanged and
retained through v1.0.0. It is experimental and unrelated to the 0.6 window.

## 6. What did not change

- JSONL schema, CLI commands and flags, exit codes, error codes.
- `docs/REPORT.md` conformance count moved 9047 → 8968 only because
  shim-surface tests were removed with their surface; no coverage was lost
  (parallel coverage lives in the owning crates).
